Leave a Trace — Examples

Small, traceable examples

1. Labeled line with two arguments

print("Expedition:", 17)
Passing the label and value adds a space automatically.

2. Three-line dispatch

print("SEARCH DISPATCH") 
print("Expedition:", 17)
print("Status:", "OVERDUE")
Each line is a separate print call.

3. Using variables

expedition = 17
status = "OVERDUE"
print("Status:", status)
Use variables to avoid repeating literal strings.

4. Capitalization matters

print("Status:", "OVERDUE")  # not 'overdue'
Strings must match exactly; tests are case-sensitive.
