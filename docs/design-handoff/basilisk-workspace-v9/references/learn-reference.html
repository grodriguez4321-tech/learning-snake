Leave a Trace — Concept: Printing Structured Output

Why this matters

Programs often present information in a structured way. In Basilisk, dispatches include a title and labeled lines. You will combine strings and values and print them on separate lines.

Goal: format a dispatch like:
SEARCH DISPATCH
Expedition: 17
Status: OVERDUE

Worked example

This example shows labeled lines using multiple print() calls.

print("SEARCH DISPATCH")
print("Expedition:", 17)
print("Status:", "OVERDUE")

Notice the label and value are passed as separate arguments, which adds a space automatically.

Key ideas

Use one print() per output line
Pass label and value as two arguments
Exact capitalization matters in strings
