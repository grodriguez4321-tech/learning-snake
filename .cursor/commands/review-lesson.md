Review the current lesson before accepting it into the curriculum.

Use the curriculum-designer and assessment-designer perspectives.

Check:

- prerequisite knowledge
- concept sequencing
- clarity of explanations
- terminology
- examples
- common mistakes
- exercise progression
- alternative valid solutions
- hidden behavioral tests
- hints
- feedback quality
- difficulty
- reuse of previously learned concepts

Do not change the lesson yet.

First return a concise review with:
1. strengths
2. problems
3. required changes
4. optional improvements

Then wait for implementation approval unless the user explicitly asked you to fix it.
